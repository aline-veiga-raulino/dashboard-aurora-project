# Limitações da análise

- **Período analisado:** a base contempla somente janeiro a junho de 2022. Não há dados suficientes para avaliar sazonalidade anual ou comparar períodos equivalentes de outros anos.
- **Empresa fictícia:** a Aurora foi criada para a atividade acadêmica; os resultados não representam uma empresa real.
- **Dependência da base:** as conclusões refletem os campos e registros disponíveis na planilha original.
- **Atualização da consulta:** o script Power Query contém um caminho local que precisa ser ajustado quando executado em outro computador.
- **Interpretação dos resultados:** os gráficos permitem comparar valores, mas não apresentam informações adicionais que expliquem as causas das diferenças entre vendedores, produtos ou meses.
