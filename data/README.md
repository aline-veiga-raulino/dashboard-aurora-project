# 📥 Base de dados

Inclua nesta pasta o arquivo original **`Vendas_.xlsx`**.

A planilha contém a aba `Consultores` e os valores mensais de janeiro a junho de 2022. Ela é utilizada como fonte da consulta Power Query disponível em `../power-query/tratamento-dados.m`.

Mantenha o nome do arquivo para corresponder ao caminho configurado na consulta. Não inclua bases com dados pessoais ou confidenciais.
